A diferença entre name e id: Qual é o papel do atributo id e do atributo name num campo de formulário? O que acontece aos dados introduzidos pelo utilizador quando um campo não tem o atributo name? Resposta: o id e o identificador unico para o navegador,elaserve para dar um nome exclusivo e unico ao certo elemento da pagina
o nome e o nome que o servidor le serve para o envio e processamento de dados formulario
Rótulos e acessibilidade: Porque é que colocar apenas um placeholder não substitui uma etiqueta <label>? Que comportamento útil acontece no navegador quando um utilizador clica em cima do texto de uma <label> corretamente configurada? Resposta: 

colocar o placeholder  nao substitiu uma etiqueta <label> porque o <placeholder> desaparece quando o utilizador começa a escrever label vai ser lido pelos leitores

Rádios vs Checkboxes: Em que circunstâncias devemos utilizar botões de rádio (type="radio") e em que casos devemos optar por caixas de verificação (type="checkbox")? Qual é a regra técnica para que vários botões de rádio pertençam ao mesmo grupo de escolha exclusiva? Resposta:  <type=radio>deve ser usado qunado o utilizador deve escolher so uma opcao
enquanto que <type=checkbox> deve ser usado quando o utilizador pode escolher inumeras opcoes ou uma,ou nenhuma
